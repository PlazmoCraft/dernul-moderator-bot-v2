# Инструкция по настройке координат баннеров приветствия и прощания

## 📝 Важная информация

Координаты аватара и текста в файле `bot/utils/welcome.py` установлены примерно и **требуют настройки** под ваши конкретные изображения `join.png` и `quit.png`.

## 🎯 Что нужно настроить

### 1. Координаты и размер аватара

В обеих функциях (`create_welcome_image` и `create_goodbye_image`) найдите следующие строки:

```python
avatar_size = 200  # Размер круглого аватара в пикселях
avatar_x = 100     # Отступ слева
avatar_y = (bg.height - avatar_size) // 2  # По центру по вертикали
```

**Как настроить:**
- `avatar_size` - диаметр круглого аватара (измерьте на вашем шаблоне)
- `avatar_x` - расстояние от левого края изображения до аватара
- `avatar_y` - расстояние от верхнего края (по умолчанию центрируется)

### 2. Координаты заголовка

```python
title_x = avatar_x + avatar_size + 100  # Отступ от аватара вправо
title_y = bg.height // 2 - 100          # Вертикальная позиция
```

**Как настроить:**
- `title_x` - горизонтальная позиция заголовка (обычно справа от аватара)
- `title_y` - вертикальная позиция заголовка (над разделяющей линией)

### 3. Координаты подзаголовка (никнейм)

```python
subtitle_y = title_y + 80  # Отступ вниз от заголовка
```

**Как настроить:**
- `subtitle_y` - вертикальная позиция подзаголовка (под разделяющей линией)
- Расстояние от заголовка можно изменить (80 пикселей по умолчанию)

### 4. Размеры шрифтов

```python
font_title = _load_minecraft_font(60)     # Размер для "ДОБРО ПОЖАЛОВАТЬ!"
font_subtitle = _load_minecraft_font(40)  # Размер для никнейма
```

**Как настроить:**
- Измените числа (60 и 40) для подбора оптимального размера текста

### 5. Цвета текста

По умолчанию используется белый текст с черной обводкой:

```python
fill="white"   # Цвет основного текста
fill="black"   # Цвет обводки
```

**Доступные цвета:**
- Названия: `"white"`, `"black"`, `"red"`, `"green"`, `"blue"`, `"yellow"`, etc.
- RGB формат: `(255, 255, 255)` для белого
- HEX формат: `"#FFFFFF"` для белого

## 🔧 Процесс настройки

### Шаг 1: Измерьте размеры вашего шаблона

Откройте `join.png` в графическом редакторе (Paint, Photoshop, GIMP) и запишите:
- Ширину и высоту изображения
- Координаты и размер места для аватара
- Координаты линий и текстовых областей

### Шаг 2: Тестовый запуск

1. Запустите бота
2. Добавьте тестового пользователя на сервер
3. Проверьте, как выглядит баннер
4. Запишите, что нужно изменить

### Шаг 3: Корректировка координат

Откройте `bot/utils/welcome.py` и измените значения:

```python
# Пример настройки для изображения 1920x1080
avatar_size = 250        # Увеличил размер аватара
avatar_x = 150           # Сдвинул правее
avatar_y = 415           # Точная вертикальная позиция

title_x = 500            # Заголовок правее аватара
title_y = 400            # Над линией

subtitle_y = 550         # Под линией
```

### Шаг 4: Тестирование длинных никнеймов

Функция автоматически уменьшает шрифт для длинных никнеймов:

```python
max_subtitle_width = bg.width - title_x - 50  # Максимальная ширина текста
font_subtitle = _fit_text_to_width(draw, subtitle_text, font_subtitle, max_subtitle_width)
```

Можно изменить `max_subtitle_width` если текст выходит за границы.

## 📐 Полезные формулы

### Центрирование по горизонтали
```python
text_x = (bg.width - text_width) // 2
```

### Центрирование по вертикали
```python
text_y = (bg.height - text_height) // 2
```

### Позиция справа от элемента
```python
new_x = element_x + element_width + offset
```

### Позиция под элементом
```python
new_y = element_y + element_height + offset
```

## 🎨 Настройка толщины обводки

По умолчанию обводка создается с толщиной 2 пикселя:

```python
for offset_x in [-2, 0, 2]:
    for offset_y in [-2, 0, 2]:
```

Для более толстой обводки измените на:
```python
for offset_x in [-3, -1, 0, 1, 3]:
    for offset_y in [-3, -1, 0, 1, 3]:
```

## 🐛 Отладка

Если что-то пошло не так, проверьте консоль бота - там будут выведены ошибки:
```
⚠️ Ошибка создания картинки приветствия: ...
```

Также можно добавить временную отладочную информацию:

```python
print(f"Размер фона: {bg.width}x{bg.height}")
print(f"Позиция аватара: ({avatar_x}, {avatar_y})")
print(f"Позиция заголовка: ({title_x}, {title_y})")
```

## 📞 Быстрая справка

| Параметр | Описание | Где находится |
|----------|----------|---------------|
| `avatar_size` | Размер круглого аватара | `create_welcome_image()`, строка ~70 |
| `avatar_x` | Позиция аватара X | `create_welcome_image()`, строка ~71 |
| `avatar_y` | Позиция аватара Y | `create_welcome_image()`, строка ~72 |
| `title_x` | Позиция заголовка X | `create_welcome_image()`, строка ~85 |
| `title_y` | Позиция заголовка Y | `create_welcome_image()`, строка ~86 |
| `subtitle_y` | Позиция подзаголовка Y | `create_welcome_image()`, строка ~104 |
| `font_title` | Размер шрифта заголовка | `create_welcome_image()`, строка ~81 |
| `font_subtitle` | Размер шрифта подзаголовка | `create_welcome_image()`, строка ~82 |
