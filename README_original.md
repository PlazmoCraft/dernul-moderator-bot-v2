Этот многофункциональный Discord-бот предназначен для автоматической модерации, управления пользователями и защиты сервера.

Бот автоматически проверяет сообщения с помощью ИИ, блокирует запрещенные слова и никнеймы, создает красивые приветственные изображения для новых участников и логирует все действия в базу данных PocketBase.

## Особенности (Features)

**Модерация и безопасность**:
*   **ИИ-фильтрация**: Анализ сообщений на токсичность и нарушения с помощью интеграции API от NVIDIA (модель `llama-3.1-nemotron-safety-guard-8b-v3`).
*   **Локальные фильтры**: Проверка сообщений и никнеймов по встроенным словарям (при обнаружении запрещенного ника дается 30 минут на смену, иначе — автоматический кик).
*   **Анти-спам**: Автоматическая выдача таймаута на 7 дней пользователю, который отправил более 3 сообщений за 5 секунд.

**Генерация приветствий**:
*   Создание персонализированной приветственной картинки для каждого нового участника.
*   Использование библиотеки `Pillow` для автоматической обрезки аватарки пользователя в круглую форму и наложения её вместе с никнеймом на шаблонный фон.

**Логирование и базы данных**:
*   Подключение к базе данных PocketBase для ведения подробных модераторских логов.
*   Автоматическая запись действий: баны, кики, муты (включая снятие мута) и удаление сообщений фильтрами.

**Удобное администрирование**:
*   Поддержка современных Slash-команд для управления сервером: `/ban`, `/kick`, `/mute`, `/unmute`, `/unban`, `/clear`.
*   Встроенная система коллективных жалоб `/report`, позволяющая пользователям в голосовом канале инициировать голосование для выдачи мута нарушителю.
*   Интерактивные кнопки верификации (`discord.ui.View`) в закрытом канале администраторов, позволяющие одобрять новых участников в один клик.
*   Команда `/status` для мониторинга нагрузки на ваш сервер хостинга (показывает использование CPU, RAM, дискового пространства, ОС и время аптайма).

## Требования (Requirements)

Для запуска бота вам потребуется:
1.  **Python 3.8+** (рекомендуется 3.10+).
2.  Аккаунт и токен бота от Discord Developer Portal (с включенными интентами `members`, `message_content`, `presences`).
3.  Ключ NVIDIA API для работы ИИ-фильтра.
4.  Настроенный и запущенный сервер **PocketBase**.

## Установка и запуск (Installation)

### 1. Подготовка файлов
Соберите все файлы проекта в одну папку. Убедитесь, что у вас есть:
*   `bot.py` (основной файл с кодом).
*   `config.py` (файл конфигурации).
*   `badwords.py` (должен содержать список `FORBIDDEN_WORDS`).
*   `badnicks.py` (должен содержать список `FORBIDDEN_NICKS`).
*   `44830476.png` (шаблонная картинка для приветствия).
*   `vcr-osd-mono-rusvhs-icons.ttf` (шрифт для генерации текста).

### 2. Установка зависимостей (Dependencies)
Откройте терминал в папке с проектом и установите необходимые библиотеки:
```bash
pip install discord.py Pillow pocketbase openai psutil

```

### 3. Конфигурация (Configuration)

В файле `config.py` вам нужно указать свои настройки. Пример структуры:

```python
TOKEN = ""
NVIDIA_API_KEY = ""

# настройки каналов
CHANNEL_ID = id
LEAVE_CHANNEL_ID = id
RULES_CHANNEL_ID = id
MAIN_SERVER_ID = id
ADMIN_CHANNEL_ID = id

# настройки ролей
OWNER_ROLE_ID = id
ADMIN_ROLE_ID = id
MEMBER_ROLE_ID = id
# tayno dernul

# Настройки PocketBase
PB_URL = ""
PB_ADMIN_EMAIL = ""
PB_ADMIN_PASSWORD = ""

```

### 4. Настройка PocketBase

Перейдите в панель управления вашего PocketBase и создайте новую коллекцию с названием `mod_logs`.
Добавьте в неё следующие текстовые поля:
* `action`
* `target_id`
* `moderator_id`
* `reason`


### 5. Запуск

Запустите бота командой:

```bash
python bot.py

```

## Технические особенности

* **Генерация графики**: Для создания круглой аватарки `Pillow` генерирует L-маску (черно-белую), применяет альфа-канал к скачанному PNG (149x149 px) и только затем встраивает его в фоновое изображение `44830476.png`.
* **Асинхронность**: Чтобы синхронные сетевые запросы к базе данных PocketBase не блокировали бота, они выполняются через обертку `asyncio.to_thread`.
* **Гибридные команды**: Команды модерации реализованы через `@bot.hybrid_command`, что позволяет использовать их как через слэш (`/ban`), так и через классический префикс (`!ban`).
