## 🎨 Особенности реализации

### Шрифт Minecraft
- Автоматическая загрузка через `ImageFont.truetype("assets/minecraft.ttf", size)`
- Fallback на стандартный шрифт при ошибке загрузки
- Поддержка кириллицы

### Круглый аватар
- Размер: 200x200 пикселей (настраивается)
- Маска: круглая через `Image.new("L")` и `draw_mask.ellipse()`
- Прозрачность: через `avatar.putalpha(mask)`

### Автоматическое масштабирование
- Функция `_fit_text_to_width()` подгоняет размер шрифта
- Минимальный размер: 20px
- Шаг уменьшения: 2px

### Обводка текста
- Толщина: 2 пикселя
- Цвет обводки: черный
- Цвет текста: белый
- Реализация через 9 итераций рисования с offset

## ⚙️ Настройка координат

**Важно!** Текущие координаты установлены примерно и требуют корректировки под ваши шаблоны.

### Параметры для настройки:

```python
# В bot/utils/welcome.py

# Аватар
avatar_size = 200    # Размер круглого аватара
avatar_x = 100       # Позиция X (слева)
avatar_y = (bg.height - avatar_size) // 2  # Позиция Y (центр)

# Заголовок
title_x = avatar_x + avatar_size + 100  # Позиция X
title_y = bg.height // 2 - 100          # Позиция Y

# Подзаголовок (никнейм)
subtitle_y = title_y + 80  # Позиция Y (под заголовком)

# Размеры шрифтов
font_title = _load_minecraft_font(60)     # Заголовок
font_subtitle = _load_minecraft_font(40)  # Подзаголовок
```

### Процесс настройки:

1. Откройте `join.png` в редакторе
2. Измерьте координаты элементов
3. Обновите значения в `bot/utils/welcome.py`
4. Протестируйте на сервере
5. Скопируйте координаты в `create_goodbye_image()`

📖 **Подробная инструкция:** `КООРДИНАТЫ_БАННЕРОВ.md`

## 🐛 Возможные проблемы

### Ошибка загрузки шрифта
```
⚠️ Не удалось загрузить шрифт minecraft.ttf, используется стандартный
```
**Решение:** Убедитесь, что `assets/minecraft.ttf` существует

### Ошибка создания баннера
```
⚠️ Ошибка создания картинки приветствия: ...
```
**Решение:** Проверьте консоль на traceback, убедитесь что `join.png` и `quit.png` существуют

### Текст не помещается
**Решение:** Увеличьте `max_subtitle_width` или уменьшите начальный размер шрифта

### Аватар не на месте
**Решение:** Настройте `avatar_x`, `avatar_y` и `avatar_size` под ваш шаблон
